## Preserve evidence and local state

The [weekly backend competition](experiments/2026-11-06-weekly-tournament/README.md)
is the latest modelling run. GW10 forecasts are frozen; actual outcomes are pending.
Score original forecasts before fitting on their finalized labels. Do not extend a
registered study retrospectively or rewrite older predictions and reports.

Baseline football and the numerical planner remain champions. Bayesian full player
scoring, strict TFT qualification, calibrated joint scenarios, social ablation and
qualified RL retain separate evidence gates. Historical model fits do not remove them.

Preserve ignored `data/`, `docs/local/`, environment files, installed dependencies
and active build directories. Public team imports can miss recent actions; reconcile
private state before personal transfer advice. Research forecasting can proceed
independently of private finances.

Local schedules run only while a worker using the matching `DATA_DIR` is alive.
Archived prompts and historical test counts do not override current status. No
transfer/chip submission, account integration, Git push or public deployment is
implied by repository maintenance.
