# Experiment registry

Reports preserve what actually ran, its source assumptions and its limitations.
Historical development results, prospective forecasts and finalized scorecards have
different evidence levels. A trained artifact does not imply production qualification.
Dated reports and their measured payloads are immutable; corrections belong in a new
report linked to the original.
